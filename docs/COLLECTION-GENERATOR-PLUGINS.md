# Collection generator plugins — superseded

**Status:** superseded — see **[AUTO-GENERATION.md](./AUTO-GENERATION.md)**

This file previously described a separate **batch generator** panel (`PieceDraft[]`, grid expand, preview-before-append). That approach is replaced by **auto generation** integrated into the Values and Properties panels:

- Per-field **auto** prompts (Values **auto** tab)
- **`[values.key]`** / **`[properties.Name]`** template inserts
- **Collection brief** and **auto settings** in the Collections panel
- **advBuilder-wide xAI key** (Electron userData secrets)
- Per-row **auto** (piece tab) + **fill empty** / **preview** (auto tab); piece-list **Auto fill** — *future (A7)*

For design, implementation status (A1–A6 done; A7–A9 future), and API reference, use [AUTO-GENERATION.md](./AUTO-GENERATION.md).
